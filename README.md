# MarktDeals Android app

Kotlin + Jetpack Compose implementation of the provided MarktDeals design.

## Screens
- Home page with popular products, best deals and new deals
- Search screen with trending searches
- Search results screen
- Product detail screen with store prices
- Clickable product cards and back/home navigation

## Open in Android Studio
1. Open the `MarktDeals` folder.
2. Let Android Studio sync Gradle.
3. Run on an Android emulator/device (API 24+).

The app is self-contained and uses sample data, so it works without a backend or API key.
