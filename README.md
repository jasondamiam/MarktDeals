# MarktDeals Android app

## Plan van aanpak
### Welke onderdelen zal er in de app worden opgenomen

Het idee van de app is een prijs prijsvergelijker voor verschillende producten uit de supermarkt. De onderdelen die ik wil toevoegen aan het app:

- Aanbiedingen van supermarkten kunnen bekijken
- Producten kunnen zoeken
- Producten per categorie kunnen bekijken
- Productinformatie kunnen bekijken
- Meldingen kunnen ontvangen

### Onderdelen voor het bouwen van het app
**Type Mobiele Applicatie:** Android-App

**Ontwikkelomgeving:** Android Studio

**Programmeertaal:** Kotlin

**Framework:** Jetpack Compose

**Hardware-specifieke functionaliteit:** Meldingen

### Waarom kies ik voor deze onderdelen
Voor het bouwen van mijn app heb ik Android Studio gekozen als mijn ontwikkelomgeving. Android Studio is een IDE (Integrated Development Environment) die is speciaal ontwikkeld voor het maken van Android applicaties. Dus in samenvatting heb ik hierbij gekozen voor native app-ontwikkeling met de programmeertaal Kotlin en het framework Jetpack Compose.

Een native applicatie wordt speciaal opgebouwd voor een bepaald besturingssysteem. In mijn geval bouw ik dit op Android. Hierdoor kan ik gebruikmaken van de mogelijkheden en functies die Android aanbiedt.

Ik heb voor Android Studio gekozen omdat dit een officiële ontwikkelomgeving van Google is voor het ontwikkelen van Android-applicaties. Ook biedt Android Studio verschillende hulpmiddelen en mogelijkheden om de applicatie bouwen en laten testen. Daarnaast met Kotlin omdat het programmeertaal werkt goed in ondersteuning in Java waar ik kennis heb en met Jetpack Compose die de gebruikersinterface opbouwen heb ik uiteindelijk gekozen voor Android Studio.

Voordat ik voor native koos, heb ik gekeken naar andere mogelijkheden. Een alternatief is Flutter, waar je applicaties kan bouwen voor meerdere besturingssysteem vanuit een codebasis (uit de programmeertaal Dart). Een ander alternatief is React Native. Dit framework maakt het mogelijk om met JavaScript of TypeScript applicaties voor verschillende mobiele platformen te ontwikkelen. Ook is het mogelijk om een webapp te ontwikkelen. Een webapp wordt via een internetbrowser geopend en hoeft niet op dezelfde manier als een native app geïnstalleerd te worden.

Met ontwikkeling bij Android Studio met Kotlin en Jetpack Compose heb ik alle benodigde hulpmiddelen om mijn app te kunnen laten werken, testen en eventuele fouten op te lossen. En ook met Native (Android) development kan ik gebruikmaken van Android-functionaliteiten, zoals notificaties. Daarom heb ik geen behoefte aan een codebasis voor meerdere besturingssystemen en kan zich focusen op een platform. Aan het einde vind ik voor mij Android Studio de beste geschikte optie is voor mij.
